# 로보택시 통합관제 대시보드 (LLM 기반)

> 2026 한이음 드림업 AI 프로젝트 — *Agentic AI 기반 로보택시 통합 운영·관제 플랫폼* 의
> **관리자(운영사)용 관제 대시보드** 구현체입니다.
> 운행 지역은 **경기도 시흥시 정왕동 일대(한국공학대학교 포함)** 로 설정되어 있으며,
> 실제 차량 데이터 대신 **백그라운드 시뮬레이터**가 50대 차량의 위치·배터리·사고·방전을
> 실시간으로 만들어내고, 화면이 WebSocket으로 바로바로 갱신됩니다.

---

## 1. 무엇이 들어 있나

- **로그인 / 회원가입** — 운영자 계정으로 접속하는 인증 게이트 (세션 쿠키, 비밀번호는 pbkdf2 해싱)
- **관제 대시보드** (`/dashboard`)
  - 좌측: 운행 차량 현황 도넛 + 범례
  - 상단: KPI 카드 4개(금일 운항 건수 / 운행 수익 / 등록 차량 / 운행 차량) + 전일 대비 증감
  - 중앙: **카카오맵** 실시간 차량 마커 (배터리 상태별 색상, 클릭 시 상세 말풍선)
  - 우측: 알림 패널(배터리 임계치·사고/방전·이벤트 피드)
  - **"🚦 도로 혼잡도"** 버튼 → 카카오맵 실시간 교통정보를 지도에 겹쳐, 네비게이션처럼
    도로별 혼잡도(원활/서행/정체)를 색으로 표시 (택시 호출 화면에서도 사용 가능)
  - "랜덤 호출 시뮬레이션" 버튼 → 배정·경로 모델 실행 후 지도에 경로 표시
- **택시 호출** (`/call`) — 운영자가 **출발지·목적지를 직접 지정**해 호출하면, 배정 모델이
  최적 차량을 골라 실제로 배차하고(해당 차량이 목적지로 출발), 경로 모델이 추천 경로를
  지도에 그려 줍니다. 지점은 드롭다운 또는 지도 클릭으로 지정할 수 있습니다.
  - **실제 도로 길찾기**: `.env` 에 `KAKAO_REST_KEY` 를 넣으면 카카오모빌리티 길찾기로
    **실제 도로 경로**를 받아 그리고, 배차된 차량이 그 도로를 따라 달립니다. 키가 없으면
    직선 경로로 자동 폴백합니다. (REST 키 발급: https://developers.kakaomobility.com —
    일반 카카오 개발자 사이트와 다른 별도 사이트. 자동차 길찾기 API는 하루 1만 건 무료.)
- **금일 이용내역** (`/trips`) — 오늘 발생한 운행/배차 기록을 한 화면에서 봅니다.
  총 이용 건수·운행 수익·평균 요금·평균 평점·수동 호출 수 요약과 함께, 자동 완료 운행과
  운영자 수동 호출이 표로 실시간 누적됩니다.
- **차량 모니터링** (`/monitor/{차량ID}`)
  - 차량 카드(번호판·상태·평점), 7개 에이전트 진행 로그 스텝퍼(현재 상태)
  - **에이전트 활동 이력** — 각 에이전트의 활동(배차·인시던트·충전·정비 등)이 시간순으로
    계속 누적되는 타임라인. 화면이 새로고침돼도 기록이 지워지지 않고 서버에 쌓입니다.
  - 배터리 / 컨디션 점수 게이지, 미니 지도, 운행 기록 테이블
- **3종 LLM 모델** (수행계획서 기준)
  1. **차량 배정 모델** — 위치·ETA·배터리·청결·예측수요를 종합해 최적 차량 배정 + 사유
  2. **위험 분석 모델** — 센서·주행 데이터로 위험 점수/등급 산출 + 조치 권고
  3. **최적 경로 탐색 모델** — 교통 상황 반영 경로/ETA/대안 경로 산출
  - **Gemini API 키가 없으면 규칙 기반으로 자동 폴백** → 키 없이도 앱은 그대로 동작

### 마커 색상 규칙 (시안과 동일)
| 상태 | 색상 |
|---|---|
| 충전 중 | 🟢 녹색 |
| 배터리 30% 이하 (위험) | 🔴 빨강 |
| 배터리 50% 이하 (주의) | 🟡 노랑 |
| 그 외 정상 운행 | ⚫ 검정 |

## 2. 사전 준비물

- **Python 3.10 이상** (3.12 권장)
- **PyCharm** (Community/Professional 무관)
- 카카오 지도 JavaScript 키 — 이미 코드에 기본값으로 들어가 있습니다.
- (선택) Google Gemini API 키 — 없어도 실행됩니다.

## 3. 파이참(PyCharm)에서 실행하기

### ① 프로젝트 열기
PyCharm → **File ▸ Open** → 압축을 푼 `robotaxi` 폴더 선택.

### ② 가상환경 + 패키지 설치
PyCharm이 `requirements.txt`를 감지하면 상단에 노란 배너로
**"Install requirements"** 가 뜹니다. 클릭하면 자동 설치됩니다.

수동으로 하려면 PyCharm 하단 **Terminal** 탭에서:
```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

### ③ 실행
- 좌측 프로젝트 트리에서 **`run.py`** 를 열고 ▶(Run) 버튼 클릭, 또는
- Terminal에서:
  ```bash
  python run.py
  ```
- 콘솔에 `http://127.0.0.1:8000` 이 표시되면 브라우저로 접속합니다.

> ⚠ **반드시 포트 8000으로 띄워야 합니다.** 카카오 디벨로퍼스에 등록한 도메인
> (`http://127.0.0.1:8000`, `http://localhost:8000` 등)과 맞아야 지도가 뜹니다.
> `run.py` 는 8000번으로 고정되어 있습니다.

### ④ 로그인
기본 관리자 계정으로 바로 로그인하거나, 회원가입으로 새 계정을 만드세요.
```
이메일   : admin@robotaxi.local
비밀번호 : admin1234
```

## 4. Gemini(LLM) 켜기 — 선택

키 없이도 "규칙 기반 모드"로 모든 기능이 동작합니다.
실제 LLM으로 돌리려면:

1. https://aistudio.google.com/apikey 에서 키 발급
2. `robotaxi` 폴더의 `.env.example` 을 복사해 `.env` 로 만들기
   ```bash
   # Windows PowerShell
   Copy-Item .env.example .env
   # macOS / Linux
   cp .env.example .env
   ```
3. `.env` 파일을 열어 키를 채우기
   ```
   GEMINI_API_KEY=여기에_발급받은_키
   ```
4. 서버 재시작 → 상단 배지가 **"● Gemini 연결됨"** 으로 바뀝니다.

> 배정/경로/위험 결과의 `engine` 값이 `gemini` 면 LLM, `rule` 이면 규칙 기반으로 처리된 것입니다.

## 5. 폴더 구조

```
robotaxi/
├─ run.py                 # 실행 진입점 (포트 8000)
├─ requirements.txt       # 의존성
├─ .env.example           # 환경설정 예시 (복사해서 .env 로)
├─ test_logic.py          # 핵심 로직 검증 스크립트 (선택 실행)
├─ app/
│  ├─ main.py             # FastAPI 앱 · 라우트 · WebSocket · 백그라운드 시뮬 루프
│  ├─ config.py           # 환경설정 로더
│  ├─ area.py             # 운행 지역 좌표 (시흥 정왕동·한국공학대 등 지점/차고지)
│  ├─ simulation.py       # 플릿 시뮬레이터 (차량 이동/배터리/사고/방전)
│  ├─ auth.py             # SQLite 사용자 + pbkdf2 비밀번호 해싱
│  └─ llm/
│     ├─ gemini.py        # Gemini 호출 래퍼 (키 없으면 None → 폴백)
│     ├─ assignment.py    # 차량 배정 모델 (+규칙 폴백)
│     ├─ risk.py          # 위험 분석 모델 (+규칙 폴백)
│     └─ route.py         # 최적 경로 탐색 모델 (+규칙 폴백)
├─ templates/             # login / signup / dashboard / monitor / call / trips
└─ static/
   ├─ css/style.css
   └─ js/dashboard.js, monitor.js, call.js, trips.js
```

## 7. 자주 묻는 문제

- **지도가 회색/빈 화면이에요**
  → 포트가 8000인지, 카카오 도메인에 `http://127.0.0.1:8000` 이 등록돼 있는지 확인하세요.
  → 브라우저 개발자도구(F12) 콘솔에 카카오 키 오류 메시지가 있는지 확인하세요.
- **`ModuleNotFoundError: fastapi`**
  → 가상환경을 활성화한 상태에서 `pip install -r requirements.txt` 를 다시 실행하세요.
- **`TypeError: cannot use 'tuple' as a dict key ...` (대시보드 진입 시 500 오류)**
  → 매우 최신 파이썬(예: 3.14)과 Jinja2 궁합 문제입니다. 본 코드는 템플릿 캐시를 꺼서
  이 문제를 우회하도록 되어 있으니 최신 zip으로 교체하면 해결됩니다. 그래도 다른 호환성
  오류가 나면 **Python 3.12** 사용을 권장합니다(가장 안정적).
- **설치 중 `Rust`/`cargo`/`building wheel`/`maturin` 류 빨간 오류**
  → 파이썬이 너무 최신이라 일부 패키지의 사전 빌드본이 없어서 그렇습니다.
  Python 3.12 로 가상환경을 만들어 설치하면 깔끔하게 해결됩니다.
- **`AttributeError: 'dict' object has no attribute 'split'` (대시보드 진입 시 500 오류)**
  → 최신 Starlette에서 `TemplateResponse` 호출 방식이 바뀌어 생기던 문제입니다.
  본 코드는 새 방식(`TemplateResponse(request, 이름, context)`)으로 작성되어 해결되어
  있으니, 최신 zip으로 교체하면 됩니다.
- **차량이 안 움직여요**
  → `.env` 의 `TICK_SECONDS` 값을 줄이면 더 자주 갱신됩니다(기본 2초).
- **포트 8000이 이미 사용 중이에요**
  → 기존에 실행 중인 서버를 끄거나, `run.py` 의 포트를 바꾸고 카카오 도메인도 함께 등록하세요.

## 8. 참고

- 이 구현은 **로컬 단일 PC 실행**에 맞춰 단순화했습니다.
  (수행계획서의 PostgreSQL/Redis/Kafka 대신 SQLite + 인메모리 시뮬레이션 + WebSocket 사용)
- 고객용 호출 앱은 이번 범위에 포함하지 않았으며, 관리자 관제 화면에 집중했습니다.
- 클라우드 배포 시에는 `SECRET_KEY` 를 반드시 임의의 긴 값으로 바꾸고,
  DB를 PostgreSQL 등으로 교체하는 것을 권장합니다.
